# § — 50 etapas

Projeto estático, pronto para GitHub Pages.

## Arquivos
- `index.html` — página principal e interface
- `style.css` — visual retrô preto/branco/azul
- `stages.js` — conteúdo das 48 fases de enigma + final
- `GABARITO.md` — respostas para o criador

## Publicação
1. Crie ou abra um repositório no GitHub.
2. Envie os arquivos para a raiz do repositório.
3. Ative GitHub Pages para a branch que contém `index.html`.
4. Abra a URL publicada.

A experiência salva o progresso no navegador. O botão `§` no canto mostra uma dica na primeira vez e a resposta na segunda.
